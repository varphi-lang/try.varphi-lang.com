How to Use This Turing Machine Simulator

This sandbox allows you to write, compile, and visualize formal computation models using Varphi, a description language for Turing machines.

Features of this simulator:

  • Multi-Tape Support: Simulate machines with an arbitrary number of tapes effortlessly. The compiler automatically adjusts the UI for the number of tapes.
  • Step-by-Step Execution: Pause, step, and inspect tape heads to debug state transitions and algorithmic logic.
  • Pre-built Examples: Instantly load classic algorithms written in Varphi, like binary addition, the busy beaver, and palindrome checkers.

What is a Turing Machine?

Invented by Alan Turing in 1936, a Turing machine is a foundational mathematical model of computation. It consists of an infinite tape divided into discrete cells, a head that reads and writes symbols, and a finite set of states dictating its actions based on a transition function. Despite its simplicity, it is capable of simulating the logic of any computer algorithm!
